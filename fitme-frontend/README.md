# fitme-frontend

React + Vite client for FitMe.

## Stack

React 18, Vite, Tailwind CSS, Zustand, React Router, Axios, Recharts, Framer Motion

## Setup

```bash
npm install
cp env.example .env
npm run dev
```

App runs at `http://localhost:5173`

## Environment Variables

```env
VITE_API_URL=http://localhost:5000/api
```

## Scripts

```bash
npm run dev      # dev server
npm run build    # production build
npm run preview  # preview build
npm run lint     # eslint
```
